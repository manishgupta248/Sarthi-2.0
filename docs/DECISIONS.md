# DECISIONS.md - why we chose things

- 27-10-2026: One Sarthi with pluggable apps, not copied projects (avoids copies drifting apart and repeated security fixes).
- 27-10-2026: Bootstrap 5 + Django templates first (simplest; JavaScript framework can come later).
- 27-10-2026: Sensitive data stays local; cloud LLMs only see non-sensitive text.
- 27-10-2026: User enters family data; no family logins at first.
- 27-10-2026: Runs only while the PC is on; missed-reminder check at startup.
- 27-10-2026: No LangChain at first; own small LLM layer that can switch between Ollama, Gemini and Grok.
- 27-10-2026: No graphics card, so local model runs on CPU as a small helper only.
- 27-10-2026: Login by username, not email (simpler; email login is hard to change later).
- 27-10-2026: Django 5.2 LTS pinned; exact versions recorded in requirements-lock.txt.
- 27-10-2026: Soft delete by default via BaseModel; hard_delete() only on purpose.
- 27-10-2026: Every log line carries a request ID; unknown errors are logged privately and shown generically.
- 27-10-2026: Django admin is the temporary data-entry screen until the dashboard (Phase 2).
- 27-10-2026: Restore is a typed PowerShell command, not a web button (replaces the whole database).
- 27-10-2026: Audit log stores changed field names only, never values (so it never becomes a second copy of private data).
- 27-10-2026: Backups are encrypted with a Fernet key kept in .env; the key must also be stored outside the PC.
- 27-10-2026: Optional second backup location (BACKUP_COPY_DIR) because a same-disk backup does not survive a disk failure.
- 27-10-2026: Sidebar menu is a registry; each app registers its own entry, so the core is never edited to add an app.
- 27-10-2026: Bootstrap files are stored locally in static/vendor (no dependency on a CDN at run time).
- 27-10-2026: Roadmap re-ordered: Family and Vault foundation (3), Wealth v1 (4), Wealth v2 (5), Tasks and Reminders (6), Telegram (7), Google (8), LLM (9), stocks/health/other apps (10).
- 27-10-2026: One encryption key (FIELD_ENCRYPTION_KEY) for encrypted fields and vault files, with an old-keys list for later rotation.
- 27-10-2026: Vault accepts PDF, JPG, PNG, docx, xlsx only; macros and legacy Office formats refused; files are never opened by Sarthi.
- 27-10-2026: Family members are plain records (Person), not login users. Nominee will be chosen from this list.
- 27-10-2026: Delete means archive (soft delete); administrators restore via the admin site.
- 27-10-2026: Idle sign-out after 30 minutes (rolling session).
- 27-10-2026: Never store passwords, PINs, CVV, OTPs or full card numbers anywhere in Sarthi.
- 27-10-2026: Wealth v1 split into 4A (accounts, snapshots, dashboard, Excel export) and 4B (transactions, reconciliation).
- 27-10-2026: Account types are an editable table seeded with Savings, Salary, PPF, NPS, Sukanya Samriddhi, DMAT, Cash or Wallet, Other.
- 27-10-2026: Joint accounts counted once under the main holder; closed accounts excluded from totals.
- 27-10-2026: Edit pages never display stored numbers; full numbers only via the audited Reveal button (30 seconds).
- 27-10-2026: Excel export is masked by default; full export needs explicit confirmation and is audited; no import for now.
- 27-10-2026: Balance older than 90 days is flagged for update.
- 27-10-2026: Dashboard widget registry added so apps add home-page cards without editing the core.
- 27-10-2026: One joint holder per account on the screen (single dropdown, deselectable).
- 27-10-2026: Remarks are separate dated encrypted entries instead of one text box.
- 27-10-2026: Documents are uploaded from the account page (one by one) through the shared vault function; the long pick-list was removed.
